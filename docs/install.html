Install X47-Win 1.1.0

Needs Windows 11 (Home or Pro). Stay on AC power. The setup GUI lets you pick a default look and which features to apply. It snapshots first so you can roll back. Disk encryption is advised but not turned on.

1. Get the kit onto C:\X47

From Linux, with the Windows partition mounted:

git clone https://github.com/sk1tzwzd/X47-Win.git
cd X47-Win
./scripts/stage-x47-windows.sh /path/to/WindowsDrive/X47

Or copy the repo’s windows/ folder to C:\X47 from Windows (USB or the dual-boot drive).

2. Boot Windows as Administrator

Shut down Linux fully. In GRUB or firmware pick Windows. Open File Explorer → C:\X47. 

Double-click Launch-X47Setup.bat
# or Install-X47Windows.bat
# first run compiles X47Setup.exe, then the wizard opens
# later: C:\X47\X47Setup.exe  or  Desktop\X47-Win Setup.exe

# console only (no GUI):
C:\X47\Install-X47Windows.bat /cli

UAC will ask for Administrator. The wizard does not write anything until the last page, Install.

3. What the setup GUI asks

  • Default look — X47 circuit is selected. Also XP, remastered XP, Vista, Win10, Win11. Change later with Apply-X47Theme.bat.
  • Features — snapshot, wallpaper, debloat, privacy, ID rotation, security, max-offline anonymity, apply look. All on by default. Uncheck to skip.
  • Optional — BitLocker + PIN, and MachineGuid spoof. Both off. Each shows a warning if you turn it on.

The kit does not format the disk or delete Documents, Pictures, or Desktop. A snapshot is written first unless you uncheck it.

Undo / roll back

If something feels wrong, boot Windows and run: 

Right-click C:\X47\Rollback-X47Windows.bat → Run as administrator
# type ROLLBACK
  • Restores registry, hosts, services, firewall, wallpaper, and NTP from the snapshot.
  • Leaves your files alone. Does not turn BitLocker off.
  • Store apps (Xbox, etc.) come back via Microsoft Store, or use System Restore and pick X47-Win before install.

4. Encrypt the disk (advised)

An unlocked Windows volume is readable from Linux and if someone pulls the drive. Use one method — do not stack BitLocker and VeraCrypt on the same volume.

BitLocker (Windows 11 Pro)

Optional helper in this kit:

C:\X47\Install-X47Windows.ps1 -EnableBitLocker
  • A 6+ digit PIN — unlocks Windows only. Ubuntu LUKS stays separate.
  • Photograph the 48-digit recovery key (USB + C:\X47\BitLocker-Recovery.txt).

Wait until encryption finishes:

manage-bde -status C:

You want 100% and Protection On. Then shut down Windows (do not hibernate). If you also run Ubuntu X47:

x47-windows-import-key /media/$USER/<USB>/X47-BitLocker-Recovery-*.txt

That helper lives in the Ubuntu X47 repo (X47 Ark / dislocker).

VeraCrypt (Home or Pro)

This kit does not install VeraCrypt. Download only from veracrypt.fr. A file container is the simple option — open it on Windows, and on Linux if you install VeraCrypt there too. Full system-disk encryption is possible; read VeraCrypt’s own dual-boot notes before you do that with GRUB. Guessing is a good way to lose the Windows boot.

Later

C:\X47\X47Setup.exe                # setup GUI again
C:\X47\Apply-X47Theme.bat          # change the look
C:\X47\Apply-X47Anonymity.bat      # security + max-offline only
C:\X47\Apply-X47Anonymity.ps1 -Revert   # undo hosts + X47-Anon firewall
C:\X47\Install-X47Windows.ps1 -EnableBitLocker   # BitLocker later
C:\X47\Install-X47Windows.ps1 -SpoofMachineGuid  # optional; breaks activation

Skip pieces of the installer with -SkipAnonymity, -SkipTheme, and similar flags. See START-HERE.txt in the kit.

Microsoft account. If the Windows user is still signed in with Microsoft, switch to a local account (Settings → Accounts → Your info) before the anonymity pass, or you can lock yourself out of that login.
