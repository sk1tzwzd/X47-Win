Install X47-Win

Needs Windows 11 Pro (BitLocker). Stay on AC power. Have a USB stick for the recovery key. If you also run Ubuntu X47 on the same PC, import the key there after encryption.

1. Get the kit onto C:\X47

From Linux, with the Windows partition mounted:

git clone https://github.com/sk1tzwzd/X47-Win.git
cd X47-Win
./scripts/stage-x47-windows.sh /path/to/WindowsDrive/X47

Or copy the repo’s windows/ folder to C:\X47 from Windows (USB or the dual-boot drive).

2. Boot Windows as Administrator

Shut down Linux fully. In GRUB or firmware pick Windows. Open File Explorer → C:\X47. 

Right-click Install-X47Windows.bat → Run as administrator

# or in an Administrator PowerShell:
Set-ExecutionPolicy Bypass -Scope Process
C:\X47\Install-X47Windows.ps1

Type YES when asked.

3. What the installer asks

  • A look (X47, XP, remastered XP, Vista, Win10, Win11) — you can change it later.
  • A 6+ digit BitLocker PIN — unlocks Windows only.
  • Photograph the 48-digit recovery key. It is also written to the USB and C:\X47\BitLocker-Recovery.txt. After encryption, Linux cannot read C:\X47 without that USB copy.

Wait until encryption finishes:

manage-bde -status C:

You want 100% and Protection On. Then shut down Windows (do not hibernate).

4. If you also run Ubuntu X47

x47-windows-import-key /media/$USER/<USB>/X47-BitLocker-Recovery-*.txt

That helper lives in the Ubuntu X47 repo. It stores ~/.config/x47/bitlocker-recovery.txt (mode 0600) for X47 Ark / dislocker.

Later, without re-doing BitLocker

C:\X47\Apply-X47Theme.bat          # change the look
C:\X47\Apply-X47Anonymity.bat      # security + max-offline only
C:\X47\Apply-X47Anonymity.ps1 -Revert   # undo hosts + X47-Anon firewall

Skip pieces of the full installer with -SkipBitLocker, -SkipAnonymity, -SkipTheme, and similar flags. See START-HERE.txt in the kit.

Microsoft account. If the Windows user is still signed in with Microsoft, switch to a local account (Settings → Accounts → Your info) before the anonymity pass, or you can lock yourself out of that login.
