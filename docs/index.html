X47-Win

A privacy kit for Windows 11: less junk, less telemetry, randomized physical NIC MACs, a snapshot you can roll back, and an optional max-offline pass. Disk encryption is advised, not required.

Install guide Security & privacy Ubuntu X47

What this is

PowerShell scripts in windows/ that you run once, as Administrator, from Windows 11 (Home or Pro). Linux only copies the folder to C:\X47. It cannot change Windows from Ubuntu.

  • Same wallpaper option as Ubuntu X47 (circuit art)
  • Debloat — Xbox, Widgets, Copilot, OneDrive, consumer junk
  • Privacy — telemetry cut to Required, ads and location off
  • Security — inbound firewall, RDP off, Defender stays on
  • Anonymity — block Microsoft accounts and telemetry hosts
  • MAC randomization — software override on every physical NIC (Wi-Fi + Ethernet)
  • Safe to try — snapshot first; undo with Rollback-X47Windows.bat (does not delete your files)
  • Encryption advised — BitLocker (optional helper) or VeraCrypt; not required to install
  • MachineGuid left alone by default. Optional -SpoofMachineGuid warns first — breaks activation, does not hide the board UUID or TPM
  • Looks — XP, remastered XP, Vista, Windows 10, or stock 11

Get the kit

Source lives on GitHub. There is no store or paid download.

git clone https://github.com/sk1tzwzd/X47-Win.git
cd X47-Win
./scripts/stage-x47-windows.sh /path/to/WindowsDrive/X47

Then boot Windows and run C:\X47\Install-X47Windows.bat as Administrator. Full steps on the install page.

Looks

Switch anytime with C:\X47\Apply-X47Theme.bat. Screenshots will land here once they are taken.
