X47-Win

A privacy kit for Windows 11 with a setup GUI: pick a default look and which features to apply. Less junk, less telemetry, randomized physical NIC MACs, a snapshot you can roll back, and an optional max-offline pass. Disk encryption is advised, not required.

Install guide Security & privacy Ubuntu X47

What this is

A setup wizard (X47Setup.exe) plus PowerShell scripts in windows/ that you run once, as Administrator, from Windows 11 (Home or Pro). Linux only copies the folder to C:\X47. It cannot change Windows from Ubuntu.

  • Same wallpaper option as Ubuntu X47 (circuit art)
  • Debloat — Xbox, Widgets, Copilot, OneDrive, consumer junk
  • Privacy — telemetry cut to Required, ads and location off
  • Security — inbound firewall, RDP off, Defender stays on
  • Anonymity — block telemetry hosts and Microsoft accounts (held back automatically while you still sign in with one)
  • MAC randomization — Ethernet software override; Wi-Fi uses Windows' per-network random address
  • Safe to try — snapshot first; undo with Rollback-X47Windows.bat (does not delete your files)
  • Encryption advised — BitLocker (optional helper) or VeraCrypt; not required to install
  • MachineGuid left alone by default. Optional -SpoofMachineGuid warns first — breaks activation, does not hide the board UUID or TPM
  • Looks — XP, remastered XP, Vista, Windows 10, or stock 11

Features

  • Snapshot + rollback — restore point and C:\X47\rollback before changes. Undo with Rollback-X47Windows.bat (type ROLLBACK). Does not delete Documents or turn BitLocker off
  • Debloat + privacy — Xbox, Widgets, Copilot, OneDrive gone; telemetry Required; ads, location, activity history off
  • Security — inbound firewall, RDP/WinRM/SMBv1 off, UAC max, Recall off, Defender on
  • Max-offline — block telemetry/Store/Xbox hosts and Microsoft accounts. Still signed in with a Microsoft account? The sign-in pieces wait until you switch to a local one. Update + Defender stay
  • MAC randomization — software override on Ethernet; Wi-Fi gets Windows' per-network random hardware address (works on drivers that refuse overrides). VPN adapters skipped. Factory MAC stays in firmware
  • Encryption — optional BitLocker helper, or VeraCrypt yourself. Not required to install
  • MachineGuid — unchanged unless -SpoofMachineGuid + type SPOOF. Breaks activation. Board UUID and TPM still identify the PC
  • Setup GUI — X47Setup.exe wizard: default look plus a checkbox for every feature
  • Looks — X47, XP, remastered XP, Vista, Win10, Win11
  • Toolbox (1.2.0) — optional scripts in windows\tools\, each re-runnable, see below
  • Not Ark — this kit does not delete the Windows partition. Reclaiming the disk for Ubuntu is X47 Ark on Linux

Toolbox

New in 1.2.0. Optional PowerShell tools in C:\X47\tools\ for after the install. Each one is safe to re-run, asks for admin only when it needs it, and logs to C:\X47\logs\.

  • Deep debloat — debloat-deep.ps1: ~60 services a home PC never uses (Xbox Live, phone/SMS/wallet, AI and telemetry hosts, enterprise and remote access, smart card, sensors), legacy features (PowerShell 2.0, Internet Explorer, Media Player, Steps Recorder) and leftover telemetry tasks. -DryRun first; -Undo restores every service. Bluetooth, Xbox controllers, camera, search and Print to PDF stay
  • Debloat extras — debloat.ps1: the Copilot desktop app, Clipchamp, Family, Widgets runtime, Start and lock-screen suggestions, Bing in Start, Edge startup boost
  • Hardening — harden.ps1: Defender back to full real-time protection with network protection, high cloud blocking and PUA blocking; telemetry tasks and SSDP/UPnP discovery off
  • Performance — performance.ps1: Best performance power mode when plugged in (battery stays Balanced), aggressive CPU boost, hardware GPU scheduling, NVIDIA Control Panel when an NVIDIA GPU is present
  • Gaming Mode — gaming-mode.ps1 -Install: a one-click taskbar button. ON switches to High performance, mutes notifications, pauses Mullvad and stops WSL; OFF puts every setting back exactly as it was
  • Vault — vault.ps1: one owner-only folder with your SSH keys, AWS config and server notes, pinned in Explorer with its own icon
  • LAN transfer with Linux — ssh-transfer.ps1 + transfer-tools.ps1: key-only SSH reachable from one LAN machine, right-click Send to, a WinSCP session and an inbox folder. Works with Mullvad on
  • Clock — timesync.ps1 syncs against Cloudflare and pool.ntp.org; timezone-auto.ps1 picks the time zone from the Wi-Fi network you join, with no location services
  • Screen capture — screen-capture.ps1: lets Snipping Tool's area/window/full-screen, screenshot/record bar work under the background-apps block; PrtSc opens it
  • Local account — local-account.ps1 -DisplayName Name: after leaving a Microsoft account, set the sign-in name, hide the email and finish the account block
  • Dev rig — dev-setup.ps1: Python, uv, Node, PowerShell 7, GitHub CLI, Rust, Go and C++ Build Tools from one package list; optional WSL2 + Debian via wsl.ps1
  • Mullvad — mullvad.ps1: auto-connect at boot with LAN allowed; optional kill switch and DNS blockers

Get the kit

Source lives on GitHub. There is no store or paid download.

git clone https://github.com/sk1tzwzd/X47-Win.git
cd X47-Win
./scripts/stage-x47-windows.sh /path/to/WindowsDrive/X47

Then boot Windows and run C:\X47\Launch-X47Setup.bat (first run builds the setup GUI). Full steps on the install page.

Looks

Switch anytime with C:\X47\Apply-X47Theme.bat. Screenshots will land here once they are taken.
