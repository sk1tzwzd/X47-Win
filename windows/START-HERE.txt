X47-Win — start here
====================

You are on the Windows partition. Do this in Windows, not Ubuntu.

1. Stay on AC power.
2. Right-click Install-X47Windows.bat → Run as administrator
   or in an Administrator PowerShell:

     Set-ExecutionPolicy Bypass -Scope Process
     C:\X47\Install-X47Windows.ps1

3. Type YES when asked.
4. Pick a look if prompted. Encryption is NOT turned on by default.

Disk encryption (advised, not required)
---------------------------------------
An unlocked Windows disk is readable from Linux and if someone pulls the drive.
Use one method, not both on the same volume:

  BitLocker (Windows 11 Pro) — optional helper in this kit:

     C:\X47\Install-X47Windows.ps1 -EnableBitLocker

    6+ digit pre-boot PIN. Photograph the 48-digit recovery key
    (USB + C:\X47\BitLocker-Recovery.txt). Wait for:
      manage-bde -status C:
    Then on Ubuntu: x47-windows-import-key /media/$USER/<USB>/X47-BitLocker-Recovery-*.txt

  VeraCrypt (Home or Pro) — not installed by this kit.
    Download only from https://www.veracrypt.fr/
    A file container is the simple option (opens on Windows and on Linux
    if you install VeraCrypt there too). Full system-disk encryption is
    possible but read VeraCrypt’s own dual-boot notes first — GRUB +
    VeraCrypt system encryption is easy to get wrong.
    Do not put VeraCrypt on a volume that already has BitLocker.

Security + max-offline anonymity (without encryption):

     C:\X47\Apply-X47Anonymity.bat

  Blocks Microsoft accounts, Store, OneDrive, Xbox, telemetry hosts.
  Defender and Windows Update stay on. Revert: Apply-X47Anonymity.ps1 -Revert
  If you use a Microsoft account: switch to a local account in Settings first.
  Your IP is still visible unless Mullvad is running on Windows.
